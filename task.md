В рамках данного задания вам необходимо реализовать простое клиент-серверное приложение, которое вы будете использовать и для выполнения последующих домашних заданий. Не обязательно писать с нуля: если у вас уже есть пет-проекты, семестровые работы, или иные веб-приложения, которые соответствуют требованиям, можно взять их.

Требования:

Приложение может быть реализовать на любом удобном вам стеке

Вы должны полностью понимать, как устроено ваше приложение

Приложение должно иметь фронтенд и бэкенд

Данные приложения должны храниться в СУБД PostgreSQL

В приложении должны быть реализованы CRUD операции над сущностями. Это понадобится для выполнения последующих домашних заданий.

Приложение должно быть реализовано в соответствии с 12 факторами (hint: если вы решили взять ранее реализованное приложение, нужно доработать его в соответствии с методологий)

Артефакты:

В качестве решения приложите архив с полным исходным кодом приложения

Архив должен содержать файл "Отчёт.md" в формате Markdown. В отчёте должны быть описаны:

Доменная область приложения

Стек реализации

Основные сущности доменной области приложения

Аргументация соответствия каждому из пунктов методологии 12 факторов, либо обоснование, почему приложение не может соответствовать этому пункту

Критерий оценки:

Представлены исходный код приложения и отчёт, артефакты соответствуют требованиям - 5 баллов

Приложение соответствует 12 факторам - 5 баллов

Советы:

предпочтительнее использовать HTTP/REST (HTTP/1.1) для взаимодействия с бэкендом, нежели gRPC, не будет проблем с домашним заданием по теме "Балансировка трафика"

предпочтительнее использовать не ресурсоёмкий стек для исключения проблем с запуском окружения в последующих домашних заданиях
