В рамках данной задачи вы запустите своё приложение в однодовой инсталляции Kubernetes - minikube. Для этого понадобится:

Установить docker по инструкции
Установить minikube по инструкции
Написать Dockerfile для сервисов вашего приложения и собрать образ(ы). Для выполнения данного пункта допускается использование ИИ-агентов.
Выполнить команду для использования docker-демона в minukube при сборке:

eval $(minikube docker-env)
Собрать образ(ы)
Загрузить локально собранный образ(ы) в minikube (инструкция):
minikube image load <образ>
Написать манифесты для развёртывания вашего приложения. Примеры манифестов приложены к материалам семинара. Перед развёртыванием необходимо потренировать выполнение основных команд kubectl для запуска нагрузок из приложенного архива.
Артефакты:

В качестве решения приложите архив со всеми использованными для сборки и развёртывания манифестами

Архив должен содержать файл "Отчёт.md" в формате Markdown. В отчёте должны быть описаны:

Какие абстракции Kubernetes использованы для запуска

Как сервисы приложения взаимодействуют между собой

Архив должен содержать скринкаст (запись экрана) длительностью не более 5-7 минут с демонстрацией процесса:

Запуска приложения и его зависимостей (kubectl apply...)

Вывода всех запущенных подов (kubect get...)

Масштабирования сервисов приложения до большего числа реплик (kubectl scale...)

Несколько кликов в UI вашего приложения, запущенного в minikube

Критерий оценки:

Представлены исходный код манифестов, использованных для запуска приложения и демонстрация экрана - 5 баллов

На демонстрации выполнены все описанные действия - 4 балла
